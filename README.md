# tghosting-bot

Telegram bot hosting project.

## Features

- Upload and manage Python/JavaScript files
- Start and stop hosted scripts
- Automatic Python dependency installation
- Node.js dependency support
- Process monitoring
- SQLite database
- Admin controls
- Force-subscription support

## Requirements

- Python 3.10+
- pip
- Node.js and npm (for JavaScript files)

## Installation

Install the required Python packages:

```bash
pip install -r requirements.txt
